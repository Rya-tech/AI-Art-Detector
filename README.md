
# AI Art Detector

## Project Description
AI Art Detector is a deep learning project
that classifies images as AI-generated or
Human-created artwork.

## Technologies Used
- Python
- PyTorch
- ResNet50
- Flask
- HTML
- CSS
- JavaScript

## Features
- Upload an image
- Detect AI-generated artwork
- Identify human-created artwork
- Display prediction results

## Installation

1. Clone this repository.
2. Install dependencies:

   pip install -r requirements.txt

3. Run the application:

   python app.py

4. Open the local URL displayed in the terminal.
